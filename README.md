One ingredient, one picture: golden honey pouring in a thick, glossy ribbon from a wooden honey dipper, glowing amber against a dark, moody background, pooling below. Nothing else in the frame — no other food, no text — just honey, close enough to taste.

Entered in [The Picture That Tastes of One](https://make.fun/bounty/the-picture-that-tastes-of-one-20261122-2047) on make.fun.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/vA-out python3 main.py
```

The program copies `entry.jpg` (the photograph beside `main.py`) to `$MAKEFUN_OUTPUT_DIR/entry.png`, creating the output directory if it does not exist. Python 3.13, standard library only, no network.
